# 🌸 Actriz OS

Un sistema operativo basado en Ubuntu 24.04, diseñado para ser ultra moderno, estético y potenciado por IA local. 

## 🏗️ Arquitectura
- **Base:** Ubuntu 24.04 LTS + X11
- **WM:** i3wm (integrado con Regolith/GNOME)
- **Estética:** Picom (Blur y Sombras), Kitty, Rofi
- **UI Personalizada:** Islas Dinámicas, Docks y Botes en Python/GTK3
- **IA Local:** Ollama (Comando `abc`)

## 📂 Estructura del Proyecto
- `/opt/actriz/`: El "molde" del sistema (configuraciones inmutables, scripts globales).
- `~/actriz/`: Espacio de usuario (proyectos, notas, configuraciones personales).
